# Лабораторная работа 4

В каталоге находится воспроизводимый эксперимент и итоговый отчёт по сравнению замены пробелов и невидимых символов Unicode.

## Состав

- `experiment.py` — встраивание, извлечение, атаки, HTML/PDF-конвертация и расчёт метрик.
- `output/results/experiment_results.csv` — данные всех 12 сочетаний метода, языка и длины сообщения.
- `output/charts/` — графики по результатам эксперимента.
- `output/samples/html/` и `output/samples/pdf/` — сгенерированные контейнеры.
- `Отчёт_ЛР4.docx` и `output/pdf/Отчёт_ЛР4.pdf` — итоговый отчёт.

## Повторный запуск

Нужен Python с пакетами `reportlab`, `pdfplumber`, `Pillow` и утилитой `pdftoppm`:

```bash
python3 experiment.py
```

Сообщение кодируется как 32-битная длина и полезная нагрузка. В методе замены пробелов битам соответствуют U+0020 и U+00A0. В методе невидимых символов используются U+200B и U+200C.
